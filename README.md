# 🎓 StudyFlow: 智慧學習與成績管理儀表板 (Project Proposal)

## 一、 專案概述
本專案旨在開發一個整合「動態課表」、「專注力計時（番茄鐘）」與「學習 ROI 數據分析」的單頁式網頁應用。透過數據視覺化，協助使用者發現學習盲點（例如：高投入、低產出的科目），並管理學期學分與成績。

*   **技術選型**：HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+).
*   **部署環境**：GitHub Pages (無需後端伺服器).
*   **資料儲存**：瀏覽器 LocalStorage (數據本地化，保護個人隱私).

---

## 二、 核心功能模組

### 1. P1: 操作中樞 (Dashboard)
*   **動態週課表**：
    *   **進度追蹤**：顯示目前日期、學期第幾週、學期總進度條。
    *   **課程備註**：支援點擊單一課程進行備註（如：`7/11 小考`）。
    *   **今日焦點**：自動提取當日的備註提醒，顯示於畫面顯眼處。
*   **智慧番茄鐘**：
    *   **標準循環**：預設 25 分鐘專注 / 5 分鐘休息。
    *   **自動關聯**：根據當前課表時間，自動預設當前計時的科目名稱。
    *   **分心紀錄**：點擊「中斷」按鈕將紀錄分心次數，用於 P2 效率評估。
*   **即時紀錄清單**：列出今日已完成的讀書時數與科目摘要。

### 2. P2: 數據分析與成績管理 (Analytics & Gradebook)
*   **關鍵指標 (Key Metrics)**：
    *   本週讀書總時數、最長連續專注連擊紀錄 (Streak)。
    *   **學分進度條**：顯示「已取得學分 / 總學分」達成率。
*   **成績與學分登記表**：
    *   **直覺編輯**：欄位包含「科目名稱」、「學分」、「期中成績」、「期末成績」。
    *   **自動統計**：整合來自 P1 的 `localStorage` 讀書時數。
*   **學習投資報酬率 (ROI) 分析**：
    *   **低回報預警**：自動標註「投入時數極高，但成績排名靠後」的科目。
    *   **高產出標籤**：標註「時數少、成績優」的科目，協助調整學習策略。
*   **資料管理工具**：
    *   **備份匯出**：將所有設定、成績、計時紀錄匯出為一個 `.json` 檔案。
    *   **備份匯入**：讀取外部 `.json` 並還原資料，確保換電腦後紀錄不中斷。

## 四、 核心實作邏輯
### 資料同步 (Cross-Page Communication)：
透過 window.addEventListener('storage', ...) 或在頁面載入時讀取 localStorage，確保 P1 的計時紀錄能即時反應在 P2 的表格中。

### 學分與成績統計：
系統自動過濾已輸入「期中/期末」成績的科目，累加對應的學分並計算達成率。

### 無後端下載 (JSON Export)：
利用 Blob 封裝 JSON.stringify(localStorage)，並透過 URL.createObjectURL 觸發下載。

### ROI 分析演算法：
根據 時數 / 成績 的比例進行加權，將表現最差的 Top 1 科目設為「效率預警」。
